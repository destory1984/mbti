# MBTI 테스트

정적 HTML 한 파일로 만든 MBTI 테스트다. 서버 없이 파일만 열어도 동작한다.

## 기능

- 24문항 퀴즈 (EI/NS/FT/JP 각 축 6문항, 축 순서로 인터리브). 전부 일상 상황 묘사형 문항이다.
- 결과 화면에 칼리코 저폴리 고양이 그림을 띄운다. 사용자 사진 한 장을 캔버스로 불러와 패치 부분만 유형별 색으로 다시 칠한다. 오렌지 패치는 F/T 축, 다크 패치는 E/I 축 색을 쓴다. N/S, J/P 축은 그림에 반영하지 않는다.
- 유형별 결과 페이지: 개요, 강점 8개, 성장 포인트 8개, 연애·일·관계·스트레스 항목, 잘 맞는 유형 4개, 부딪힐 수 있는 유형 2개. 16유형 전부 따로 썼다.
- 배경은 Three.js로 도형 16개를 띄운 장식용. 캐릭터 자체는 2D 캔버스로 그린다.

## 실행

`index.html`을 브라우저로 열면 된다. 빌드나 설치 과정이 없다.

디버그용 URL 파라미터:
- `index.html?type=ISTJ` — 퀴즈를 건너뛰고 해당 유형 결과 화면으로 바로 간다.
- `index.html?showcase=10000` — 16유형을 10000ms 간격으로 자동으로 넘긴다.

## 파일 구성

| 파일 | 용도 |
|---|---|
| `index.html` | 앱 본체 (HTML+CSS+JS 한 파일). 수정은 여기서 한다. |
| `publish.html` | Claude 아티팩트 게시용으로 문서 래퍼 태그만 뺀 파생 파일. `index.html`을 고치면 다시 만들어야 한다. |
| `assets/cat-ref-v2.png` | 재채색에 쓰는 원본 고양이 사진 (알파 채널 포함 PNG). |
| `mbti-preview.png` | 공유용 썸네일 이미지. |
| `NOTES.md` | 개발 진행 기록. 설계 결정, 시도했다 버린 방법, 남은 작업 목록이 들어 있다. |
